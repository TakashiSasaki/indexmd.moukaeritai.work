# Runtime-Generated Data Directory

This directory contains local metadata catalogues and runtime-generated validation logs.

## Files

- `models_info.json`: Static Gemini models catalog.
- `validation_history.json`: Local execution logs generated by the indexing validator runtime.

## 🔒 Security and Privacy Guard

To prevent private document details, file names, or generated summaries from being committed to Git:
- `validation_history.json` and any other history JSON files are ignored via `.gitignore`.
- Do not commit real, un-sanitized validation logs or private developer run traces.
